Lolcats

Lolcats is an app that I made as an excuse to set up a'my own home server. It's a simple file sharing utility, and one of few projects which I actually occasionally use.

This is the first dynamic app I finished. I made a file sharing service first because it was a fairly quick and easy project, but still served as a good introduction to developing dynamic apps in Sveltekit. I even made a full auth system with JWTs, but then I disabled account registration because I wanted better control over who could make accounts. So that might have been a bit unnecessary, but it was fun and I did learn a fair amount (previously I had only ever done "real" auth in PHP).
